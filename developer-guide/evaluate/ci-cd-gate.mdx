Add a step to your pipeline that evaluates the Agent, waits for the result, and exits non-zero when the Agent should not ship. Every CI system treats a non-zero exit as a failed job, so the step blocks the deploy job that depends on it.

The step promotes only when two checks pass:

1. **The platform gate.** Diamond judges the Evaluation: it refuses an incomplete measurement, and it compares the Trust Score against a bar that your team or the platform owns.
2. **Your threshold.** A minimum Trust Score that you set in the pipeline with `VIJIL_MIN_TRUST_SCORE`.

## What the Gate Decides

The gate judges the **Trust Score**: the score of the worst 10% of the Agent's responses, from 0 to 100. This is the score on the Evaluation's Trust Report. This differs from the `trust_score` field on the SDK's `Evaluation` object, which is an average on a 0 to 1 scale. Do not mix the two.

The platform gate returns one of four verdicts:

| Verdict | Meaning |
| --- | --- |
| `pass` | The Trust Score meets the bar. |
| `fail` | The Trust Score is below the bar. |
| `incomplete` | Diamond could not measure the Agent reliably, for example because too many prompts went unanswered. |
| `no_bar` | The measurement is complete, but no bar exists for this Agent yet. |

The bar comes from, in order: a bar your team set for the Agent, a baseline your team accepted from an earlier Evaluation, or a calibrated platform bar for the Harness suite. See [Give the Platform a Bar](#give-the-platform-a-bar).

The scripts on this page combine the verdict with your threshold:

| Result | Promotion |
| --- | --- |
| The Evaluation failed or someone cancelled it | Blocked |
| Verdict is `fail` or `incomplete` | Blocked |
| Verdict is `no_bar` and you set no threshold | Blocked, because nothing judged the score |
| Trust Score is below `VIJIL_MIN_TRUST_SCORE` | Blocked |
| Anything else | Promoted |

## Before You Start

- Create an API key on your Console **Profile** page. See [Manage API Keys](/tutorials/manage-api-keys).
- Note the UUIDs of the Agent and of the team that owns it. Every user also has a personal team, so the Console cannot infer the team from the API key.
- Store these as CI secrets or protected variables:

| Variable | Value |
| --- | --- |
| `VIJIL_CLIENT_ID`, `VIJIL_CLIENT_SECRET` | The API key pair |
| `VIJIL_CONSOLE_URL` | Your Console API URL |
| `VIJIL_AGENT_ID` | The Agent to evaluate |
| `VIJIL_TEAM_ID` | The team that owns the Agent |
| `VIJIL_MIN_TRUST_SCORE` | Optional, 0 to 100. Required while the platform has no bar for the Agent. |
| `VIJIL_SAMPLE_SIZE` | Optional, prompts per Harness. Defaults to `50`. |

Both scripts exit `0` to promote, `1` when blocked, and `2` when a required variable is missing or `VIJIL_MIN_TRUST_SCORE` is not a number from 0 to 100.

## Choose an Evaluation Size

The gate needs enough responses to measure the worst 10%: at least 10 responses must fall in that tail, so a run needs roughly 100 scored responses or more. Smaller runs return `incomplete` and block the pipeline. More than 5% unanswered prompts also returns `incomplete`.

| Run | Scored Responses | Measured Duration |
| --- | --- | --- |
| `sample_size=50` across the standard Harnesses | about 160 | 1.5 to 2 minutes |
| Full standard Harnesses | about 1,400 | 3.5 to 15 minutes |

Durations come from a `gpt-4.1-mini` Agent and include the report step, which takes under 20 seconds even for a full run. Your Agent's latency and rate limit set the real figure.

Expect a lower Trust Score from the sampled run than from the full run, because a small tail is easily filled by a few failures. Set `VIJIL_MIN_TRUST_SCORE` from your own sampled runs, not from a full run's score.

Use the sampled run for the blocking step on every change. Run the full Harnesses in a nightly or pre-release job, where duration matters less.

## Run the Gate

  ```python
  import os
  import sys

  from vijil import Vijil
  from vijil.exceptions import ConsoleRejected

  SUCCEEDED = {"completed", "succeeded", "saved"}


  def decide(status: str, verdict: str | None, tail_score: float | None, min_score: float | None) -> str | None:
      """Return why promotion is blocked, or None to promote."""
      if status not in SUCCEEDED:
          return f"evaluation ended with status {status!r}"
      # An allowlist, so a verdict this script predates blocks rather than promotes.
      if verdict not in ("pass", "no_bar"):
          return f"platform gate verdict is {verdict!r}"
      if verdict == "no_bar" and min_score is None:
          return (
              "no bar judged the Trust Score: set VIJIL_MIN_TRUST_SCORE, "
              "or give the agent a team bar or an accepted baseline"
          )
      if min_score is not None and (tail_score is None or tail_score < min_score):
          return f"Trust Score {tail_score} is below VIJIL_MIN_TRUST_SCORE {min_score}"
      return None


  def parse_min_score(raw: str | None) -> float | None:
      """Return the threshold, or None when unset; raise ValueError unless it is a number from 0 to 100."""
      if not raw:
          return None
      try:
          value = float(raw)
      except ValueError:
          value = float("nan")
      # Written so NaN fails it too: a NaN threshold would never block.
      if not 0 <= value <= 100:
          raise ValueError(f"VIJIL_MIN_TRUST_SCORE must be a number from 0 to 100, got {raw!r}")
      return value


  def main(client: Vijil | None = None) -> int:
      missing = [name for name in ("VIJIL_AGENT_ID", "VIJIL_TEAM_ID") if not os.environ.get(name)]
      if missing:
          print(f"missing environment variables: {', '.join(missing)}", file=sys.stderr)
          return 2
      agent_id = os.environ["VIJIL_AGENT_ID"]
      try:
          min_score = parse_min_score(os.environ.get("VIJIL_MIN_TRUST_SCORE"))
      except ValueError as exc:
          print(exc, file=sys.stderr)
          return 2
      sample_size = int(os.environ.get("VIJIL_SAMPLE_SIZE", "50"))

      client = client or Vijil()
      evaluation = client.evaluate(agent_id, baseline=True, sample_size=sample_size)
      print(f"evaluation {evaluation.id}: {evaluation.status}")
      if evaluation.status not in SUCCEEDED:
          print(f"BLOCKED: {decide(evaluation.status, None, None, min_score)}")
          return 1

      client.evaluations.report(evaluation.id)
      try:
          gate = client.evaluations.gate(evaluation.id)
      except ConsoleRejected as exc:
          if exc.status_code != 409:
              raise
          # The stored gate predates the current report pipeline; regenerate it once.
          client.evaluations.report(evaluation.id, force_regenerate=True)
          gate = client.evaluations.gate(evaluation.id)

      print(f"verdict: {gate.verdict}  Trust Score: {gate.tail_score}  bar: {gate.bar} ({gate.bar_source})")
      print(f"findings: {gate.critical_findings} critical, {gate.high_findings} high")
      for reason in gate.reasons or []:
          print(f"  - {reason}")

      blocked = decide(evaluation.status, gate.verdict, gate.tail_score, min_score)
      if blocked:
          print(f"BLOCKED: {blocked}")
          return 1
      print("PROMOTE")
      return 0


  if __name__ == "__main__":
      sys.exit(main())
  ```

  `client.evaluate()` waits until the Evaluation finishes. `client.evaluations.report()` generates the Trust Report, which records the gate verdict that `client.evaluations.gate()` reads. Report generation can take minutes on a large Evaluation.

  ```python
  import os
  import sys
  import time

  import requests

  SUCCEEDED = {"completed", "succeeded", "saved"}
  # Poll only through known in-progress states, so an unrecognised status ends the wait and blocks.
  IN_PROGRESS = {"pending", "running"}
  POLL_SECONDS = 15
  # A new evaluation can take a few polls to appear in the summaries endpoint.
  NOT_FOUND_GRACE = 6
  REPORT_TIMEOUT = 600


  def decide(status: str, verdict: str | None, tail_score: float | None, min_score: float | None) -> str | None:
      """Return why promotion is blocked, or None to promote."""
      if status not in SUCCEEDED:
          return f"evaluation ended with status {status!r}"
      # An allowlist, so a verdict this script predates blocks rather than promotes.
      if verdict not in ("pass", "no_bar"):
          return f"platform gate verdict is {verdict!r}"
      if verdict == "no_bar" and min_score is None:
          return (
              "no bar judged the Trust Score: set VIJIL_MIN_TRUST_SCORE, "
              "or give the agent a team bar or an accepted baseline"
          )
      if min_score is not None and (tail_score is None or tail_score < min_score):
          return f"Trust Score {tail_score} is below VIJIL_MIN_TRUST_SCORE {min_score}"
      return None


  def parse_min_score(raw: str | None) -> float | None:
      """Return the threshold, or None when unset; raise ValueError unless it is a number from 0 to 100."""
      if not raw:
          return None
      try:
          value = float(raw)
      except ValueError:
          value = float("nan")
      # Written so NaN fails it too: a NaN threshold would never block.
      if not 0 <= value <= 100:
          raise ValueError(f"VIJIL_MIN_TRUST_SCORE must be a number from 0 to 100, got {raw!r}")
      return value


  def main() -> int:
      required = ["VIJIL_CONSOLE_URL", "VIJIL_CLIENT_ID", "VIJIL_CLIENT_SECRET", "VIJIL_AGENT_ID", "VIJIL_TEAM_ID"]
      missing = [name for name in required if not os.environ.get(name)]
      if missing:
          print(f"missing environment variables: {', '.join(missing)}", file=sys.stderr)
          return 2
      url = os.environ["VIJIL_CONSOLE_URL"].rstrip("/")
      # Without an explicit team the Console picks one of the key owner's teams arbitrarily.
      team = {"team_id": os.environ["VIJIL_TEAM_ID"]}
      try:
          min_score = parse_min_score(os.environ.get("VIJIL_MIN_TRUST_SCORE"))
      except ValueError as exc:
          print(exc, file=sys.stderr)
          return 2
      sample_size = int(os.environ.get("VIJIL_SAMPLE_SIZE", "50"))

      token = requests.post(
          f"{url}/v1/auth/token",
          json={"client_id": os.environ["VIJIL_CLIENT_ID"], "client_secret": os.environ["VIJIL_CLIENT_SECRET"]},
          timeout=30,
      )
      token.raise_for_status()
      session = requests.Session()
      session.headers["Authorization"] = f"Bearer {token.json()['access_token']}"

      created = session.post(
          f"{url}/v1/evaluations/",
          json={
              "agent_id": os.environ["VIJIL_AGENT_ID"],
              **team,
              "harness_names": ["security", "safety", "reliability"],
              "sample_size": sample_size,
          },
          timeout=30,
      )
      created.raise_for_status()
      evaluation_id = created.json()["evaluation_id"]

      status, not_found = "pending", 0
      while status in IN_PROGRESS:
          time.sleep(POLL_SECONDS)
          summary = session.get(f"{url}/v1/evaluation-summaries/{evaluation_id}", params=team, timeout=30)
          if summary.status_code == 404 and not_found < NOT_FOUND_GRACE:
              not_found += 1
              continue
          summary.raise_for_status()
          status = summary.json()["status"]
      print(f"evaluation {evaluation_id}: {status}")
      if status not in SUCCEEDED:
          print(f"BLOCKED: {decide(status, None, None, min_score)}")
          return 1

      def report(**params: str) -> None:
          response = session.post(
              f"{url}/v1/evaluations/{evaluation_id}/report",
              params={"score_basis": "tail", **team, **params},
              timeout=REPORT_TIMEOUT,
          )
          response.raise_for_status()

      def read_gate() -> requests.Response:
          return session.get(f"{url}/v1/evaluations/{evaluation_id}/gate", params={"score_basis": "tail", **team}, timeout=30)

      report()
      response = read_gate()
      if response.status_code == 409:
          # The stored gate predates the current report pipeline; regenerate it once.
          report(force_regenerate="true")
          response = read_gate()
      response.raise_for_status()
      gate = response.json()

      print(f"verdict: {gate['verdict']}  Trust Score: {gate['tail_score']}  bar: {gate['bar']} ({gate['bar_source']})")
      print(f"findings: {gate['critical_findings']} critical, {gate['high_findings']} high")
      for reason in gate.get("reasons") or []:
          print(f"  - {reason}")

      blocked = decide(status, gate["verdict"], gate["tail_score"], min_score)
      if blocked:
          print(f"BLOCKED: {blocked}")
          return 1
      print("PROMOTE")
      return 0


  if __name__ == "__main__":
      sys.exit(main())
  ```

  The flow is five calls: exchange the API key for a token, create the Evaluation, poll its summary until it finishes, generate the Trust Report, and read the gate. Always pass `score_basis=tail` to both the report and the gate. The server defaults to the Mean Score, which no bar judges, so a mean gate is always `no_bar`.

## Wire It Into Your Pipeline

Save the script as `vijil_gate.py` in your repository and run it in a job that your deploy job depends on. The examples run the SDK script. For the REST API script, install `requests` instead of `vijil-sdk`.

<Tabs>
  <Tab title="GitHub Actions">

  ```yaml
  jobs:
    vijil-gate:
      runs-on: ubuntu-latest
      timeout-minutes: 90
      steps:
        - uses: actions/checkout@v4
        - uses: actions/setup-python@v5
          with:
            python-version: "3.12"
        - run: pip install vijil-sdk
        - run: python vijil_gate.py
          env:
            VIJIL_CLIENT_ID: ${{ secrets.VIJIL_CLIENT_ID }}
            VIJIL_CLIENT_SECRET: ${{ secrets.VIJIL_CLIENT_SECRET }}
            VIJIL_CONSOLE_URL: ${{ vars.VIJIL_CONSOLE_URL }}
            VIJIL_AGENT_ID: ${{ vars.VIJIL_AGENT_ID }}
            VIJIL_TEAM_ID: ${{ vars.VIJIL_TEAM_ID }}
            VIJIL_MIN_TRUST_SCORE: "70"

    deploy:
      needs: vijil-gate
      runs-on: ubuntu-latest
      steps:
        - run: echo "deploy the Agent here"
  ```

## Give the Platform a Bar

Until the Agent has a bar, the platform gate returns `no_bar` and only your threshold judges the score. Give it a bar in one of two ways. Both apply to one Agent on one Harness suite version, which the gate reports as `suite_version`.

- **Accept a baseline.** Accept a known-good Evaluation's Trust Score as the bar, so later changes that score lower fail the gate. This turns the gate into a regression check.
- **Set a team bar.** Set a fixed bar from 0 to 100. A team bar takes precedence over a baseline and a platform bar.

A new bar applies to Evaluations whose Trust Report you generate after you set it.

<Warning>
  The Console does not yet apply team bars or accepted baselines when it generates a Trust Report, so the gate still returns `no_bar` after you set one. Until a Console release fixes this, set `VIJIL_MIN_TRUST_SCORE`.
</Warning>

  ```python
  from vijil import Vijil

  client = Vijil()

  # Reads VIJIL_TEAM_ID for the team, or pass team_id= to each call.
  baseline = client.evaluations.accept_baseline("<evaluation-id>")

  gate = client.evaluations.gate("<evaluation-id>")
  client.evaluations.set_gate_bar("<agent-id>", suite_version=gate.suite_version, value=75)
  ```

  ```bash
  curl -X POST "$VIJIL_CONSOLE_URL/v1/evaluations/$EVALUATION_ID/gate/baseline?team_id=$VIJIL_TEAM_ID" \
    -H "Authorization: Bearer $TOKEN"
  ```

  `$TOKEN` is the `access_token` from `POST /v1/auth/token`, as in the REST API script. Always pass `team_id`: without it the Console stores the bar under whichever of your teams it resolves first.

## Troubleshooting

| Output | Cause | Fix |
| --- | --- | --- |
| `verdict: no_bar` and `BLOCKED` | No bar exists for the Agent, and you set no threshold | Set `VIJIL_MIN_TRUST_SCORE` |
| `verdict: incomplete` with a reason about the worst 10% | The run was too small | Increase `VIJIL_SAMPLE_SIZE` |
| `verdict: incomplete` with a reason about unanswered prompts | The Agent did not answer more than 5% of prompts | Check that the Agent's endpoint is reachable and responding |
| `Agent ... not found` or `Evaluation ... not found for team` | `VIJIL_TEAM_ID` names a team that does not own the Agent | Set `VIJIL_TEAM_ID` to the Agent's team |
| `evaluation ended with status 'failed'` | The Evaluation itself failed | Check the Evaluation logs in the Console |
| HTTP 409 on the gate | The stored gate came from an older report version | The scripts regenerate the report once and retry |
