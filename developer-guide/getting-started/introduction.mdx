## The Problem with Testing Agents

Traditional software testing catches bugs, but Agents also fail in ways that do not look like bugs. They hallucinate confidently, follow requests they should refuse, and behave differently under adversarial pressure than in demos. Your unit and integration tests can pass even when your Agent remains vulnerable in production.

This guide shows you how to catch those failures before deployment. You'll learn to run behavioral evaluations against adversarial [Scenarios](/concepts/evaluation-components/scenario), use Red Team evaluations for adaptive attacks, integrate trust gates into your CI/CD pipeline, and add runtime protection that blocks attacks your evaluations did not anticipate.

<Info>
If you manage Agents through a web Console rather than code, see the [Agent Owner Guide](/owner-guide/getting-started/introduction). This guide focuses on programmatic integration.
</Info>

## What You Get from Vijil

Vijil provides two products that work together:

**Diamond** offers two evaluation types. Behavioral evaluations send adversarial Probes to your agent and produce a Trust Score for reliability, security, and safety. Red Team evaluations run adaptive waves of attacks and produce findings and a report.

**[Dome](/developer-guide/protect/overview)** scans Agent inputs and outputs at runtime. Your application or framework integration can use the scan result to block or sanitize flagged content, while `secure_agent()` can apply configured Trust Runtime controls.

## What Vijil Measures

Behavioral evaluations test agents across three dimensions:

| Dimension | What It Measures | Example Failures |
|-----------|------------------|------------------|
| **Reliability** | Does the Agent complete intended tasks accurately and consistently? | Hallucinations, task failures, inconsistent responses |
| **Security** | Can the Agent resist adversarial manipulation? | Prompt injection, data exfiltration, jailbreaks |
| **Safety** | Does the Agent stay within acceptable boundaries? | Policy violations, harmful content, unauthorized actions |

Each behavioral evaluation produces a **Trust Score** (0–100) with breakdowns by dimension. The score tells you where your Agent is strong, where it is vulnerable, and whether it meets your deployment threshold. Red Team evaluations instead produce evidence of attacks, vulnerabilities, and successful strategies in a report.

## Time to First Trust Score

Start with [MCP](/developer-guide/agentic/quickstart) to use natural-language requests from Claude Code. For terminal automation, configure the [CLI](/developer-guide/cli/setup). For custom or non-Python integrations, follow the [REST API path](/developer-guide/agentic/quickstart). For Python code, install and configure the [SDK](/developer-guide/sdk/setup). Then [run an Evaluation](/developer-guide/evaluate/running-evaluations) and add [Dome protection](/developer-guide/protect/overview) when you need runtime controls.

All four paths require access to a [Vijil Console gateway](/developer-guide/deploy-vijil/deploy-vijil-console) and a registered [Agent](/owner-guide/register-agents/what-is-an-agent) endpoint.

## Integration Points

Vijil integrates with the tools you already use:

| Framework | Integration |
|-----------|-------------|
| **LangChain / LangGraph** | `GuardrailRunnable` for chains, `LocalAgentExecutor` for evaluation |
| **Google ADK** | Before/after callbacks for Dome, ADK Runner for evaluation |
| **Custom Python** | Wrap any function that takes a prompt and returns a response |
| **CI/CD** | GitHub Actions, GitLab CI, or any system that can run Python |
