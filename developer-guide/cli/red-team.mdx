Red Team is a [Diamond](/developer-guide/evaluate/overview) evaluation type that tests a registered Agent through adaptive waves. Each wave generates attack seeds, runs attackers, judges their results, and reflects on what worked before planning the next wave. The evaluation produces findings and a report rather than a Trust Score.

Each Red Team run and its results share one `evaluation_id`. Use `vijil evaluate` to start the evaluation, then use `vijil evaluations redteam-*` to inspect it.

## Start a Red Team Evaluation

Run a Red Team evaluation and wait for a terminal status:

```bash
vijil evaluate "$AGENT_ID" --type redteam
```

The command prints progress while the evaluation runs. Its terminal statuses are `succeeded`, `failed`, `cancelled`, and `degraded`. A `degraded` evaluation finished with some attacker failures; inspect its status details before using the report.

Add `--no-wait` to return immediately after creation. Save the evaluation ID from the output for later commands:

```bash
vijil evaluate "$AGENT_ID" --type redteam --no-wait
export EVALUATION_ID="<evaluation-id>"
```

### Configure the Evaluation

Pass a JSON object through `--redteam` to override the default wave settings:

```bash
vijil evaluate "$AGENT_ID" \
  --type redteam \
  --redteam '{"max_waves": 3, "max_seeds_per_wave": 5}'
```

The configuration accepts these fields:

| Field | Description |
| --- | --- |
| `min_waves` | Lower bound for adaptive waves |
| `max_waves` | Upper bound for adaptive waves |
| `max_seeds_per_wave` | Seed limit for each wave |
| `max_parallel_attackers` | Concurrent attacker limit |
| `attack_execution` | Attack timeout settings |
| `taxonomy_file` | Risk taxonomy file |
| `advanced` | Attempts, retries, strategies, turns, and text gradient settings |

Red Team runs directly against the registered Agent. It does not accept `--baseline`, `--bespoke`, `--sample-size`, `--local`, or `--harness-name`.

## Inspect Progress and Evidence

| Command | Description |
| --- | --- |
| `vijil evaluations redteam-status <evaluation-id>` | Show run and wave progress |
| `vijil evaluations redteam-seeds <evaluation-id>` | List generated attack seeds |
| `vijil evaluations redteam-attacks <evaluation-id>` | List attacks or return one attack |
| `vijil evaluations redteam-judgments <evaluation-id>` | List judgments or return one judgment |
| `vijil evaluations redteam-reflections <evaluation-id>` | List reflections or return one wave's reflection |
| `vijil evaluations redteam-report <evaluation-id>` | Retrieve the final report |

Each command accepts `--team <team-id>`. If you omit it, the CLI uses the default team from your configuration.

### Status

Show the evaluation's status, current phase, wave progress, attacker counts, errors, and degradation details:

```bash
vijil evaluations redteam-status "$EVALUATION_ID"
```

Use the global output option before the command when you need JSON:

```bash
vijil --output json evaluations redteam-status "$EVALUATION_ID"
```

### Seeds

Seeds describe the risks and instructions that attackers explore. List every seed or filter by wave:

```bash
vijil evaluations redteam-seeds "$EVALUATION_ID"
vijil evaluations redteam-seeds "$EVALUATION_ID" --wave "$WAVE_ID"
```

### Attacks

Attack results include the attacker type, execution status, transcript, and error details. List results by evaluation or wave:

```bash
vijil evaluations redteam-attacks "$EVALUATION_ID"
vijil evaluations redteam-attacks "$EVALUATION_ID" --wave "$WAVE_ID"
```

Return one attack by combining `--wave` and `--seed`:

```bash
vijil evaluations redteam-attacks "$EVALUATION_ID" \
  --wave "$WAVE_ID" \
  --seed "$SEED_ID"
```

### Judgments

Judgments record whether an attack succeeded, whether it could cause harm, and whether the response leaked artifacts:

```bash
vijil evaluations redteam-judgments "$EVALUATION_ID"
vijil evaluations redteam-judgments "$EVALUATION_ID" --wave "$WAVE_ID"
```

Return one judgment by combining `--wave` and `--seed`:

```bash
vijil evaluations redteam-judgments "$EVALUATION_ID" \
  --wave "$WAVE_ID" \
  --seed "$SEED_ID"
```

### Reflections

After each completed wave, the evaluation summarizes successful seeds, saturated outcomes, and new strategy patterns. List all reflections or select one wave:

```bash
vijil evaluations redteam-reflections "$EVALUATION_ID"
vijil evaluations redteam-reflections "$EVALUATION_ID" --wave "$WAVE_ID"
```

## Retrieve the Report

The final report summarizes vulnerabilities, policy violations, leaked artifacts, and successful strategies. JSON is the default format:

```bash
vijil evaluations redteam-report "$EVALUATION_ID"
```

Choose Markdown or PDF with `--format`. Use `--output` to write the report to a file; PDF output requires it:

```bash
vijil evaluations redteam-report "$EVALUATION_ID" \
  --format md \
  --output red-team-report.md

vijil evaluations redteam-report "$EVALUATION_ID" \
  --format pdf \
  --output red-team-report.pdf
```

Add `--force-regenerate` to rebuild a cached PDF:

```bash
vijil evaluations redteam-report "$EVALUATION_ID" \
  --format pdf \
  --output red-team-report.pdf \
  --force-regenerate
```

For the shared behavioral and Red Team startup options, see the [CLI evaluation guide](/developer-guide/cli/evaluate).
