This quickstart takes you from authentication to a completed behavioral Evaluation. Choose one interface and follow its tab through each step.

| Interface | Best For | Requirements |
|-----------|----------|--------------|
| **CLI** | Terminal workflows and CI/CD | `vijil-sdk`; Python 3.11–3.13 |
| **SDK** | Python applications and notebooks | `vijil-sdk`; Python 3.11–3.13 |
| **REST API** | Custom integrations and non-Python applications | An HTTP client and a bearer token |
| **MCP** | Natural-language workflows in Claude Code | `vijil-mcp`; Python 3.10+ |

<Note>
The [`vijil-mcp`](https://pypi.org/project/vijil-mcp/) server is a separate package that uses `vijil-console` under the hood. It does not share the `vijil-sdk` installation or configuration.
</Note>

## Prerequisites

- A [Vijil Console deployment](/developer-guide/deploy-vijil/deploy-vijil-console) and its API gateway URL
- Vijil credentials: a client ID and client secret, or a bearer access token
- A provider API key for the Agent endpoint you want to test
- [Claude Code](https://claude.ai/code) if you choose MCP

## Run Your First Evaluation

<Steps>
  <Step title="Install Your Interface">
    <Tabs>
      <Tab title="CLI">
        Install `vijil-sdk`, which includes the `vijil` CLI:

        ```bash
        python -m pip install vijil-sdk
        vijil --help
        ```
      </Tab>
      <Tab title="SDK">
        Install the Python SDK:

        <CodeGroup>
        ```bash pip
        python -m pip install vijil-sdk
        ```

        ```bash Poetry
        poetry add vijil-sdk
        ```
        </CodeGroup>

        Verify the import:

        ```bash
        python -c "from vijil import Vijil; print('ok')"
        ```
      </Tab>
      <Tab title="REST API">
        No Vijil package is required. Save the API gateway URL for the following requests:

        ```bash
        export VIJIL_URL="https://console-api.example.com"
        ```
      </Tab>
      <Tab title="MCP">
        Install the standalone MCP server:

        <CodeGroup>
        ```bash pip
        python -m pip install vijil-mcp
        ```

        ```bash pipx
        pipx install vijil-mcp
        ```
        </CodeGroup>

        Verify the server is available:

        ```bash
        vijil-mcp --help
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="Configure and Authenticate">
    <Tabs>
      <Tab title="CLI">
        Save the Console gateway, then export the API credential pair created in the Console:

        ```bash
        vijil config set gateway.url https://console-api.example.com
        export VIJIL_CLIENT_ID="vk_..."
        export VIJIL_CLIENT_SECRET="..."
        vijil auth status
        ```

        The CLI exchanges the pair for a bearer token when it creates the client. If you already have a bearer token, set `VIJIL_API_KEY` or run `vijil auth login` and paste the token. Interactive login saves it to `~/.vijil/credentials.json`.

        If your credentials do not resolve a team automatically, pin one in `~/.vijil/config.toml`:

        ```bash
        vijil config set defaults.team_id <team-id>
        ```
      </Tab>
      <Tab title="SDK">
        Export a Console API credential pair and construct the client:

        ```bash
        export VIJIL_CLIENT_ID="vk_..."
        export VIJIL_CLIENT_SECRET="..."
        ```

        ```python
        from vijil import Vijil

        client = Vijil(gateway="https://console-api.example.com")
        ```

        `Vijil()` reads the credential pair from the environment and exchanges it for a bearer token. You can instead provide an existing bearer token through `VIJIL_API_KEY` or `Vijil(api_key="<access-token>")`.
      </Tab>
      <Tab title="REST API">
        Exchange your Console email and password for a bearer token:

        ```bash
        curl -s -X POST "$VIJIL_URL/v1/auth/jwt/login" \
          -H "Content-Type: application/json" \
          -d '{"email": "user@example.com", "password": "your-password"}'
        ```

        Copy the response's `access_token`, then list your team memberships and save the team you want to use:

        ```bash
        export TOKEN="eyJhbG..."

        curl -s "$VIJIL_URL/v1/users/me/teams" \
          -H "Authorization: Bearer $TOKEN"

        export TEAM_ID="c58aea71-..."
        ```
      </Tab>
      <Tab title="MCP">
        Configure the `vijil-console` CLI used by the MCP server:

        ```bash
        vijil auth init --url https://console-api.example.com
        vijil auth login
        vijil team use <team-id>
        ```

        Create `.mcp.json` in your project root:

        ```json
        {
          "mcpServers": {
            "vijil": {
              "type": "stdio",
              "command": "vijil-mcp"
            }
          }
        }
        ```

        Start Claude Code from that directory so it can discover the server and its tools.
      </Tab>
    </Tabs>
  </Step>

  <Step title="Register an Agent">
    The example below registers an OpenAI-compatible chat-completions endpoint. Keep provider credentials in environment variables instead of command history or source control.

    <Tabs>
      <Tab title="CLI">
        ```bash
        export OPENAI_API_KEY="sk-..."

        vijil agents create \
          --name "My Chat Agent" \
          --model "gpt-4o" \
          --url "https://api.openai.com/v1/chat/completions" \
          --api-key-env OPENAI_API_KEY \
          --protocol chat_completions
        ```

        Copy the returned Agent `id`, then confirm the Agent is available:

        ```bash
        export AGENT_ID="a1b2c3d4-..."
        vijil agents list
        ```
      </Tab>
      <Tab title="SDK">
        ```python
        import os

        agent = client.agents.create(
            name="My Chat Agent",
            url="https://api.openai.com/v1/chat/completions",
            model_name="gpt-4o",
            api_key=os.environ["OPENAI_API_KEY"],
            protocol="chat_completions",
        )

        print(agent.id, agent.agent_name)
        ```
      </Tab>
      <Tab title="REST API">
        ```bash
        export OPENAI_API_KEY="sk-..."

        curl -s -X POST "$VIJIL_URL/v1/agent-configurations/" \
          -H "Authorization: Bearer $TOKEN" \
          -H "Content-Type: application/json" \
          -d "{
            \"agent_name\": \"My Chat Agent\",
            \"model_name\": \"gpt-4o\",
            \"agent_url\": \"https://api.openai.com/v1/chat/completions\",
            \"api_key\": \"$OPENAI_API_KEY\",
            \"protocol\": \"chat_completions\"
          }"
        ```

        Copy the returned Agent `id`:

        ```bash
        export AGENT_ID="a1b2c3d4-..."
        ```
      </Tab>
      <Tab title="MCP">
        Ask Claude Code to register the endpoint. Do not paste provider secrets into the prompt; provide them only through the credential mechanism supported by your Agent configuration.

        <Prompt description="Register an Agent named My Chat Agent that uses gpt-4o through the OpenAI chat-completions endpoint, and show me the resulting Agent ID.">
        Register an Agent named My Chat Agent that uses gpt-4o through the OpenAI chat-completions endpoint, and show me the resulting Agent ID.
        </Prompt>
      </Tab>
    </Tabs>
  </Step>

  <Step title="Run a Baseline Evaluation">
    A baseline Evaluation uses the standard reliability, security, and safety <a href="/concepts/evaluation-components/harness">Harnesses</a>. The sample size limits how many <a href="/concepts/evaluation-components/probe">Probes</a> Vijil selects from each Harness.

    <Tabs>
      <Tab title="CLI">
        ```bash
        vijil evaluate "$AGENT_ID" --baseline --sample-size 50
        ```

        The command waits by default, prints progress, and returns the completed Evaluation. Copy its `id`:

        ```bash
        export EVAL_ID="e5f6a7b8-..."
        ```
      </Tab>
      <Tab title="SDK">
        ```python
        evaluation = client.evaluate(
            agent.id,
            baseline=True,
            sample_size=50,
        )

        print(evaluation.id, evaluation.status)
        ```

        `client.evaluate()` polls every five seconds by default and returns the persisted Evaluation summary after the run reaches a terminal state.
      </Tab>
      <Tab title="REST API">
        Start the asynchronous Evaluation:

        ```bash
        curl -s -X POST "$VIJIL_URL/v1/evaluations/" \
          -H "Authorization: Bearer $TOKEN" \
          -H "Content-Type: application/json" \
          -d "{
            \"agent_id\": \"$AGENT_ID\",
            \"team_id\": \"$TEAM_ID\",
            \"harness_names\": [\"reliability\", \"security\", \"safety\"],
            \"sample_size\": 50
          }"
        ```

        Save the returned `evaluation_id`, then poll the status endpoint until the Evaluation reaches a terminal state:

        ```bash
        export EVAL_ID="e5f6a7b8-..."

        curl -s "$VIJIL_URL/v1/evaluations/$EVAL_ID" \
          -H "Authorization: Bearer $TOKEN"
        ```
      </Tab>
      <Tab title="MCP">
        <Prompt description="Run a behavioral Evaluation for Agent a1b2c3d4-… with the reliability, security, and safety Harnesses, sample 50 Probes per Harness, wait for completion, and show me the Evaluation ID.">
        Run a behavioral Evaluation for Agent a1b2c3d4-… with the reliability, security, and safety Harnesses, sample 50 Probes per Harness, wait for completion, and show me the Evaluation ID.
        </Prompt>
      </Tab>
    </Tabs>
  </Step>

  <Step title="Inspect the Results">
    <Tabs>
      <Tab title="CLI">
        Show the completed Evaluation and the Agent's latest [Trust Score](/concepts/trust-score/introduction):

        ```bash
        vijil evaluations show "$EVAL_ID"
        vijil scores show "$AGENT_ID"
        ```

        Inspect only the prompt-response rows from failed Probes:

        ```bash
        vijil evaluations responses "$EVAL_ID" --status failed
        ```
      </Tab>
      <Tab title="SDK">
        Read the overall and per-dimension scores from the returned Evaluation:

        ```python
        print(evaluation.trust_score)
        print(evaluation.dimensions.reliability)
        print(evaluation.dimensions.security)
        print(evaluation.dimensions.safety)
        ```

        Retrieve the complete nested results or only failed prompt-response rows:

        ```python
        results = client.scores.results(evaluation.id)
        failures = client.evaluations.responses(
            evaluation.id,
            status="failed",
        )
        ```
      </Tab>
      <Tab title="REST API">
        Retrieve the persisted score summary and the complete nested results:

        ```bash
        curl -s "$VIJIL_URL/v1/evaluation-summaries/$EVAL_ID?team_id=$TEAM_ID" \
          -H "Authorization: Bearer $TOKEN"

        curl -s "$VIJIL_URL/v1/evaluation-results/$EVAL_ID/results?team_id=$TEAM_ID" \
          -H "Authorization: Bearer $TOKEN"
        ```
      </Tab>
      <Tab title="MCP">
        <Prompt description="Show the Trust Score, dimension scores, and failed Probe responses for Evaluation e5f6a7b8-…">
        Show the Trust Score, dimension scores, and failed Probe responses for Evaluation e5f6a7b8-…
        </Prompt>
      </Tab>
    </Tabs>
  </Step>

  <Step title="Download the Report">
    You generate Trust Reports on demand after Evaluations complete.

    <Tabs>
      <Tab title="CLI">
        `reports download` generates the report first when necessary:

        ```bash
        vijil reports download "$EVAL_ID" --path .
        ```
      </Tab>
      <Tab title="SDK">
        `client.reports.download()` also generates a missing report before retrying the download:

        ```python
        pdf_bytes = client.reports.download(evaluation.id)

        with open("report.pdf", "wb") as report_file:
            report_file.write(pdf_bytes)
        ```
      </Tab>
      <Tab title="REST API">
        Generate the report, then download its PDF:

        ```bash
        curl -s -X POST \
          "$VIJIL_URL/v1/evaluations/$EVAL_ID/report?team_id=$TEAM_ID" \
          -H "Authorization: Bearer $TOKEN"

        curl -s \
          "$VIJIL_URL/v1/evaluations/$EVAL_ID/pdf?team_id=$TEAM_ID" \
          -H "Authorization: Bearer $TOKEN" \
          -o report.pdf
        ```
      </Tab>
      <Tab title="MCP">
        <Prompt description="Generate a Trust Report for Evaluation e5f6a7b8-… and tell me how to retrieve it.">
        Generate a Trust Report for Evaluation e5f6a7b8-… and tell me how to retrieve it.
        </Prompt>
      </Tab>
    </Tabs>
  </Step>
</Steps>

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| `vijil` is not found | Install `vijil-sdk` in the active Python environment and verify its scripts directory is in `PATH` |
| SDK or CLI authentication fails | Set both `VIJIL_CLIENT_ID` and `VIJIL_CLIENT_SECRET`, or provide a bearer token through `VIJIL_API_KEY` |
| Requests reach the wrong deployment | Run `vijil config set gateway.url <gateway-url>` or pass `gateway=` to `Vijil()` |
| A team-scoped operation fails | Run `vijil auth status`; if authentication resolves no team, set `defaults.team_id` in `~/.vijil/config.toml` |
| The Evaluation service cannot reach the Agent | Verify the Agent URL, protocol, provider API key, and network accessibility |
| MCP tools do not appear | Verify `.mcp.json` is in the project root, confirm `vijil-mcp` is in `PATH`, and restart Claude Code |
| Report generation lacks a team | Pass `team_id=`, set `defaults.team_id`, or authenticate with a token that includes a team claim |
